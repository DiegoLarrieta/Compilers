1. El lenguaje en un vistazo

BabyDuck es un mini-lenguaje imperativo. Un programa tiene un nombre, variables globales opcionales, funciones void opcionales y un bloque main. Solo hay dos tipos de dato (int y float) y cinco estatutos: asignación, condición, ciclo, llamada a función e impresión.

program ejemplo;
var i, total : int;
    promedio : float;

void muestra(valor : int) [
    {
        print("valor", valor);
    }
];

main {
    i = 0;
    total = 0;
    while (i < 10) do {
        total = total + i * 2;
        i = i + 1;
    };
    if (total > 50) {
        muestra(total);
    } else {
        print("total chico");
    };
    promedio = total / 10.0;
}
end

2. Expresiones regulares de los elementos léxicos

Los únicos elementos que necesitan una expresión regular "de verdad" son los identificadores y las constantes. Las palabras reservadas, operadores y signos de puntuación son texto fijo.

ElementoExpresión regularAceptaRechaza
Identificador[A-Za-z_][A-Za-z0-9_]*x total_2 _aux2x mi-var
Constante entera[0-9]+0 42 0074a
Constante flotante[0-9]+\.[0-9]+3.14 0.5.5 3.
Letrero (string)"[^"\n]*""hola mundo" ""comillas sin cerrar, saltos de línea
Espacios (se ignoran)[ \t\r\n]+No generan token; los saltos de línea solo se cuentan para reportar errores.
  • El signo de un número no es parte de la constante: -5 son dos tokens (- y 5). El signo lo maneja la gramática en FACTOR.
  • Una palabra reservada tiene forma de identificador. Primero se reconoce como identificador y después se consulta la tabla de palabras reservadas.
  • El lenguaje distingue mayúsculas de minúsculas: if es palabra reservada, If es un identificador.

5. Gramática libre de contexto

Cada diagrama se convirtió en reglas BNF. Los nombres en MAYÚSCULAS son tokens de la sección 3, los nombres en minúsculas son no terminales y ε es la cadena vacía. El símbolo inicial es programa.

Como BNF no tiene "opcional" ni "repetir", cada uno se escribe con una regla auxiliar:

  • Opcional: una regla con dos alternativas, el elemento o ε (por ejemplo vars_opt, else_opt).
  • Repetición: una regla recursiva (por ejemplo estatutos ::= estatuto estatutos | ε).
  • Lista separada por comas: lista ::= elemento COMMA lista | elemento.

La precedencia de los operadores queda expresada en los niveles de la gramática, sin reglas extra: expresion (relacionales) llama a exp (+ -), que llama a termino (* /), que llama a factor. Lo que está más abajo se agrupa primero.

Supuestos que hay que comparar contra el archivo del curso

Los diagramas de la sección 4 se redibujaron a partir de la definición conocida de BabyDuck, no del archivo original del curso. Antes de entregar conviene revisar estos puntos contra ese archivo:

  • Operadores relacionales: aquí son >, < y !=. Si el diagrama incluye ==, hay que agregar un token y una alternativa en op_rel.
  • El signo unario (+ o -) solo se permite antes de un identificador o una constante, no antes de un paréntesis.
  • if y while terminan con ; después de su bloque, y la función termina con ];.
  • El lenguaje no tiene comentarios.
