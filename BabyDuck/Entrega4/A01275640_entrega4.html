2. Distribución de direcciones virtuales

En los cuádruplos ya no aparecen nombres sino números. Cada dato recibe una dirección virtual según el segmento al que pertenece y su tipo. Cada combinación tiene un rango de 1000 direcciones:

SegmentointfloatboolletreroQué guarda
Global1000 – 19992000 – 2999Variables del var del programa.
Local3000 – 39994000 – 4999Parámetros y variables de una función.
Temporal5000 – 59996000 – 69997000 – 7999Resultados intermedios de una función o de main.
Constante8000 – 89999000 – 999910000 – 10999Números y letreros que aparecen en el programa.

Decisiones de diseño

  • El rango dice el segmento y el tipo. Con solo comparar rangos se sabe que 6003 es un temporal float. La máquina virtual no necesita guardar el tipo aparte (segmento_y_tipo() en memoria.py).
  • Locales y temporales se reinician en cada función. Cada llamada tendrá su propia copia de esa memoria, así que las direcciones de dos funciones distintas pueden coincidir sin chocar. Main también empieza sus temporales desde 5000.
  • bool solo existe como temporal, porque en BabyDuck no se pueden declarar variables bool: solo resultan de > < !=.
  • Cada constante distinta recibe una sola dirección (tabla de constantes). Si 1 aparece diez veces, las diez usan 8000. Los letreros de print son constantes de tipo letrero.
  • Los parámetros son locales. Reciben las primeras direcciones locales de la función, en orden. PARAM copia el argumento a esa dirección.
  • Si un segmento se llena (más de 1000 datos de un tipo), el compilador reporta un error.

3. Cuádruplos nuevos

CuádruploSignificado
(GOTO, _, _, n)Brincar al cuádruplo n.
(GOTOF, cond, _, n)Si cond es falsa, brincar al cuádruplo n; si es verdadera, seguir con el siguiente.
(ERA, _, _, f)Reservar la memoria local y temporal de la función f (sus recursos en el directorio).
(PARAM, arg, _, dir)Copiar el valor de arg (en la memoria de quien llama) a la dirección dir del parámetro (en la memoria nueva de f).
(GOSUB, f, _, n)Guardar a dónde regresar y brincar al cuádruplo n, donde empieza f.
(ENDFUNC, _, _, _)Terminar la función: liberar su memoria y regresar después del GOSUB.
(END, _, _, _)Fin del programa.

Los de la entrega 3 (+ - * / > < != = neg print) son iguales, pero con direcciones. main.py imprime cada cuádruplo dos veces: con direcciones (lo que de verdad se genera) y, al lado, con nombres, solo para leerlo.

4. Estatutos condicionales y cíclicos

El problema: cuando se genera el GOTOF de un if, todavía no se sabe a dónde brincar, porque el cuerpo aún no se ha traducido. La solución es generar el salto con el destino pendiente, guardar su número en la pila de saltos (PSaltos) y rellenarlo cuando se llegue al destino. Para poder rellenar el cuádruplo n se cambió la fila: ahora es una lista con índice al frente, con acceso por posición en O(1) (en la entrega 3 era un deque, que cuesta O(n) para llegar a un elemento de en medio).

EstatutoForma de los cuádruplos
if (c) { A };
   cuádruplos de c  → t
   GOTOF t, _, fin
   cuádruplos de A
fin:
if (c) { A } else { B };
   cuádruplos de c  → t
   GOTOF t, _, inicioB
   cuádruplos de A
   GOTO _, _, fin
inicioB:
   cuádruplos de B
fin:
while (c) do { A };
regreso:
   cuádruplos de c  → t
   GOTOF t, _, fin
   cuádruplos de A
   GOTO _, _, regreso
fin:

Como PSaltos es una pila, los estatutos anidados funcionan solos: el salto que se rellena siempre es el del estatuto más interno que sigue abierto.

La pila de saltos paso a paso

program saltos;
var a, b : int;
main {
    while (a < 3) do {
        if (a > b) {
            b = a;
        } else {
            b = 0;
        };
        a = a + 1;
    };
}
end

5. Declaración e invocación de funciones

Declaración

  • El código de las funciones se genera antes que el de main, así que el cuádruplo 1 es (GOTO, _, _, ???). Se rellena al llegar a main.
  • Después de declarar parámetros y variables se anota en el directorio el número del siguiente cuádruplo: ahí empieza la función.
  • Al terminar el cuerpo se genera ENDFUNC y se guardan los recursos que usó la función.

Invocación: f(arg1, arg2);

  1. Al leer f: se verifica que exista y se genera (ERA, _, _, f).
  2. Por cada argumento: se traducen los cuádruplos de su expresión, se saca su resultado de PilaO, se valida con el cubo que su tipo se pueda asignar al parámetro k (a un float se le puede pasar un int, al revés no) y se genera (PARAM, resultado, _, dirección del parámetro k).
  3. Al leer ): se valida que el número de argumentos sea el de parámetros y se genera (GOSUB, f, _, inicio de f).

La función se agrega al directorio antes de traducir su cuerpo y su inicio se conoce antes del primer estatuto, así que una función puede llamarse a sí misma.

programas/funciones.bd

program funciones;
var total : int;
    promedio : float;

void suma(a : int, b : int) [
    {
        total = a + b;
    }
];

void escala(valor : float, veces : int) [
    var k : int;
    {
        k = 0;
        while (k < veces) do {
            valor = valor * 2.0;
            k = k + 1;
        };
        promedio = valor;
    }
];

void cuenta(n : int) [
    {
        if (n > 0) {
            print(n);
            cuenta(n - 1);
        };
    }
];

main {
    suma(3, 4 * 2);
    escala(total, 3);
    escala(1.5, total - 9);
    cuenta(3);
    print("total", total, "promedio", promedio);
}
end

program ciclos;
var i, j, pares : int;
main {
    i = 0;
    pares = 0;
    while (i < 10) do {
        j = i / 2 * 2;
        if (j != i) {
            print(i, "es impar");
        } else {
            pares = pares + 1;
        };
        i = i + 1;
    };
    if (pares > 3) {
        print("muchos pares", pares);
    };
}
end
