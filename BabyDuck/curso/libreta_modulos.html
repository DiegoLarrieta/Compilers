Ejercicio Módulos: program pelos

Cuádruplos, recursos de cada módulo y memoria de ejecución.

El programa

program pelos;
var int i, j, k;

int uno (int j)
var int i;
{ i = j + (k - j*2 + j);
  if (j > 0)
     { return ( uno (i - j) ); }
  else
     { return ( i + k ); }
}

void dos (int i, int j)
var int x, y;
{ x = i + j;
  if (x > j * k)
     { print ( uno (x - k) ); }
  else
     { print ( uno (j) ); }
}

main ( )
{ read (k);
  i = 5;  j = i * 2 + i;
  dos (j - i, j);
}

Reglas que usé (las de clase)

  • uno regresa int → tiene una variable global con su nombre (uno) donde se guarda lo que regresa. Por eso aparece en la memoria global.
  • return x → (RETURN, _, _, x): guarda x en la global uno y se sale de la función.
  • Llamada: ERA al leer el nombre → se evalúa cada argumento → PARAM → GOSUB.
  • Si la función regresa valor, justo después del GOSUB se copia la global a un temporal: (=, uno, _, tN). Así una segunda llamada no la pisa.
  • Los temporales se numeran desde t1 en cada módulo.

Cuádruplos

En el cuádruplo 15 el GOTO nunca se ejecuta, porque el RETURN del 14 ya se salió. Se genera igual porque el if-else siempre pone un GOTO al final del bloque verdadero.

Recursos

Global4 var (i, j, k, uno)3 temp
UNO2 var-par (j, i)8 temp
DOS4 var-par (i, j, x, y)6 temp

Así es como se cuenta: var-par son los parámetros más las variables locales. Temp es el número del temporal más alto que usa el módulo: UNO llega a t8, DOS a t6 y main a t3.

Memoria de ejecución

mem globalmem DOSmem UNO (1ª llamada)mem UNO (llamada recursiva)

Truco para revisar: en uno, i = j + (k − 2j + j) = k. ¡Siempre vale k! Entonces:

  • si j > 0 → regresa uno(k − j)
  • si j ≤ 0 → regresa k + k = 2k

k=3: uno(15) → uno(−12) → 6  ·  k=0: uno(25) → uno(−25) → 0  ·  k=10: uno(15) → uno(−5) → 20 ✓

Tarea

Tarea Módulos: program patito

El programa

program patito;
var  int i, j, k;
     float f;

void uno (int a, int b)
{  if (a > 0)
     {  i = a + b * j + i;
        print ( i + j );
     }
   else
     {  print ( a + b );  }
}

void dos (int a, float g)
{  int i;
   i = a;
   while (a > 0)
   {  a = a - k * j;
      uno (a * 2, a + k);
      g = g * j - k;
   }
}

main ()
{  i = 2;  k = i + 1;
   f = 3.14;
   do
   {  dos (i + k, f * 3);
      print (i, j * 2, f * 2 + 1.5);
      i = i - k / 2;
   } while (i > 0);
}

Antes de empezar, ojo con esto

  • uno no declara variables, así que su i es la global. En dos hay un int i local que tapa a la global.
  • Las funciones son void: no hay variable global de retorno ni RETURN. Terminan con ENDFUNC.
  • do { } while (c): el cuerpo se ejecuta primero y la condición va al final. Si es verdadera se regresa, así que uso GOTOV (goto si verdadero).
  • Con float: f * 3, g * j, f * 2 + 1.5 dan temporales float. k / 2 es int / int → int.

Cuádruplos

Recursos

Globalvar: 3 int (i, j, k) · 1 float (f)temp: 5 int · 3 float · 1 bool
UNOvar-par: 2 int (a, b)temp: 5 int · 1 bool
DOSvar-par: 2 int (a, i) · 1 float (g)temp: 4 int · 2 float · 1 bool

Total de temporales: main t1–t9, UNO t1–t6, DOS t1–t7. Las bool son los resultados de >.

Si te piden ejecutarlo: este programa no termina. Lo comprobé corriendo los cuádruplos.

  • j nunca recibe valor. Si vale 0, en dos la línea a = a − k * j deja a a igual, y el while (a > 0) se cicla.
  • Si j valiera 1, dos sí termina, pero uno le suma a la i global (i = a + b*j + i) más de lo que main le resta (k / 2 = 1), así que el do-while (i > 0) nunca acaba.

Por eso aquí solo van cuádruplos y recursos. Si la profesora pide memoria de ejecución, pregúntale qué valor tiene j.
